# Changelog - Plugin hyundaikia

## v1.0.0 (2025-06-01)
### Ajouts
- Support Hyundai, Kia, Genesis
- Toutes régions : Europe, USA, Canada, Chine, Australie, Inde
- Import des véhicules depuis le compte Bluelink/UVO
- Commandes info : batterie EV, carburant, verrouillage, portes, vitres, pneus, GPS, odomètre, batterie 12V
- Commandes action : verrouiller/déverrouiller, démarrer/arrêter moteur, climatisation, charge EV
- Gestion des limites de charge AC/DC (slider)
- Widget dashboard avec barre de niveau et actions rapides
- Template mobile
- Compatibilité Debian 12 / Python 3.11+ (gestion PEP 668)
- Rafraîchissement automatique configurable (cache ou depuis le véhicule)
