# Plugin Jeedom - hyundaikia

Contrôlez et surveillez vos véhicules **Hyundai**, **Kia** et **Genesis** depuis Jeedom.

## Installation rapide
1. Copier le dossier `hyundaikia` dans `/var/www/html/plugins/`
2. Activer le plugin dans Jeedom
3. Installer les dépendances (bouton dans Plugins > Gestion des plugins)
4. Configurer vos identifiants Bluelink/UVO
5. Rechercher et importer vos véhicules
